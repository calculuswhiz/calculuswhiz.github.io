# NeverEverThrow

My own knockoff version of [NeverThrow](https://github.com/supermacro/neverthrow). It started as a pet project to show I didn't need NPM, but after developing some of the features, I think this does a better job.

That said, I did take a lot of inspiration from NeverThrow and had to peek at the implementation a bit, especially for the signatures of the ResultAsync types.
